# Khwahish

A responsive shared wishlist for saving products, organizing personal and shared libraries, and tracking price history.

## Product direction

- Personal and shared libraries with profile-based sign-in.
- Save products from a link or screenshot and review extracted details before saving.
- Keep the initial price and dated price observations.
- Search and query saved items across libraries the user can access.
- Add retailer integrations only where product and pricing data can be accessed under permitted terms.

## Planned stack

- Next.js, TypeScript, and responsive web UI.
- Supabase Auth, Postgres, Row Level Security, and private Storage.
- Vercel for hosting and server-side endpoints.
- On-device OCR for screenshots in the browser, with manual correction.
